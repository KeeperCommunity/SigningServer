# Security reporting

Please report vulnerabilities privately to the Bitcoin Keeper maintainers through GitHub's private vulnerability reporting for this repository when available, or through the contact channel on [Bitcoin Keeper's website](https://bitcoinkeeper.app/). Do not disclose exploit details, credentials, wallet material, or user data in public issues.

This repository contains source code only. It does not grant access to production services or signing keys. Do not use real wallet material in tests or examples.
