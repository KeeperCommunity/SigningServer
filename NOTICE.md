# Origin, licenses, and attribution

Signing Server was forked in 2020 from [BHServer](https://github.com/thecryptobee/BHServer), whose package metadata declared the ISC license and Parsh as author. Subsequent work was contributed in the private BitHyve SigningServer repository by BitHyve and other contributors. This public repository starts with a fresh history to exclude historical credentials; it does not represent the original authorship chronology.

The public distribution and new KeeperCommunity contributions use the [MIT license](LICENSE). The inherited Signing Server code retains the [ISC copyright and permission notice](LICENSE-ISC). Both notices must be preserved when distributing the complete work. The package metadata expresses these cumulative obligations as `MIT AND ISC`; it does not claim that earlier contributors relicensed their original work solely under MIT.

Third-party packages retain their own licenses; see the lockfile and each package's license.
